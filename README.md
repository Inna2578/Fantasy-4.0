# Атлас историй 4.0 — писательская мастерская

Автономное веб-приложение на русском языке. Работает без API-ключей, регистрации и сетевых вызовов: оригинальные идеи строятся на шаблонах, а дальнейшая работа — ручная и полностью редактируемая.

## Возможности
- Все возможности версии 3: 8 POV, 9 сюжетных структур, жанры, герои, мир, магическая система, планы.
- «Книга»: рабочее название, логлайн, синопсис, ставки, тема, финал, статистика рукописи.
- «Линии»: редактируемые сюжетные линии A/B/C и разные уровни конфликта, добавление/удаление.
- «Главы»: редактируемая структура, POV, черновик текста, статус, перестановка, добавление/удаление.
- «Сцены»: цель, конфликт, поворот, итог, глава, POV, статус, порядок сцен, фильтр по главам.
- «Библия мира»: анкеты героев, законы магии, культура и дополнительные записи (места, предметы, термины, хронология).
- «Проверка»: автоматические эвристические проверки заполненности и связей, не претендующие на ИИ-анализ смысла.
- Автосохранение на устройстве через localStorage; экспорт Markdown и полный резервный JSON-проект.
- Архив избранного JSON из версий 2/3/4; автоматический перенос локальных данных с того же адреса GitHub Pages.

## Установка на GitHub Pages
1. **Скачайте полный архив проекта отдельно в JSON** в вашей текущей версии, если в ней есть важные сохранения.
2. Распакуйте ZIP. Загрузите **содержимое** этой папки в корень существующего репозитория GitHub, заменив `index.html`, `sw.js`, `manifest.webmanifest` и прочие файлы.
3. Откройте адрес GitHub Pages. Если прежняя версия остаётся в кэше, обновите страницу или полностью перезапустите установленную PWA.
4. На iPhone/iPad: Safari → Поделиться → На экран «Домой».

**Важно:** работа сохраняется локально в конкретном браузере. Если меняете домен или очищаете данные сайта, импортируйте сохранённый JSON. Рекомендуется скачивать JSON после каждой значительной сессии.

**Смены структуры:** изменение типа структуры не стирает ранее написанные главы. Кнопка «Новый автоплан» перезаписывает их после предупреждения: предварительно скачайте JSON.
